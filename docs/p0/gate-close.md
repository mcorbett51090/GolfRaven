## Verdict

All 8 final-gate SHOULD-FIX items (F-S1 to F-S7, plus A-6) and all 8 NITs were reproduced against `b78bdb6`, and
all are closed. The earlier properties still hold: signup indistinguishability, N1/A-1 link preservation, the N2/A-3
retention gate, the K2 refusals, and argv-only git calls. Install, typecheck, build and test are green, and the tree
is clean.

The F-S2/F-S3 rewrite introduced one new defect, **G-S1**. A malformed pre-day-0 bullet un-excludes every address
listed before day 0 as soon as the bullet is fixed after day 0. HEAD's own strict parse forces that fix, so the
failure path is the tool's normal remediation flow. It inflates the K2 count with exit 0, which contradicts
Addendum F. The fix is a few lines in `parseExclusionSetLenient` plus one integration test.
