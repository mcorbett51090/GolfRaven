## Checked and found sound

- **Only listed URLs are fetched; there is no GolfNow search or crawling.** `grep -rn golfnow tools/p0/src` hits only doc comments and the `golfnowFacilityUrl` field. `x4-verify` fetches exactly the map's URLs; no links are followed and no search URLs are built.
- **Addendum F name match is reused unchanged.** `namesMatch` (`overpass-geo.ts:318`): NFKD, all `\p{M}` stripped, lower-cased, non-letter/digit → space, collapsed, then equality or whole-word containment. `x4-verify` calls it with the page text as the haystack.
- **Per-trail coverage.** A `null` URL and a non-live page both count against the trail's size. The 80% boundary is correct (P7). No combined figure is computed. The replay round-trip test passes.
- **x2-verdict core rules are correct.** A SHA not in the manifest refuses (throws, exit 1). All three facts are required. The pass bar is 2 of 3. Both sides of each comparison are whitespace-collapsed. Matching is case-sensitive, i.e. verbatim.
- **Block detection separates both proxy-block shapes from a site's own status.** It uses the `x-deny-reason` header or a policy-specific body text; a generic "Access Denied" or "Forbidden" body is **not** classed as a block. A thrown error counts as a block only on a 403 plus connect/tunnel/proxy signature, so timeouts and DNS failures stay `error`. The misreport risk runs the other way: blocks and errors are counted as results (B1, S5), not site 403s mistaken for blocks.
- **x5-overpass User-Agent refactor.** It produces the same UA string (same default contact text) and the same Latin-1 guard; only the error wording is now generic. The x5 tests pass.
- **Exit codes.** `p0-desk` exits 1 on any `blocked` or `error` row, and 0 on `skipped` only. The code is correct as written; the gaps are the partial-block cases in B1 and S5.
