# X1 (=K4a) — Health real-device test

## Check (verbatim, plan §10 P0)

> **Health real-device test** (**2 elapsed days**: a real round is ~4 h, then an Android pass). One real round
> from 3 sources (Garmin watch + Connect Mobile; Apple Watch Workout; one phone golf app) on iOS, then an
> equivalent Android pass. Inspect `workoutActivityType`, `HKWorkoutRoute`, `HKSource.bundleIdentifier`, and the
> Health Connect exercise type / route / `dataOrigin`. **Harness (G-P0-06):** iOS = Apple Health's export
> (`export.xml` + its per-workout route GPX files) `[unverified — training knowledge]`, no code needed; Android =
> a minimal Health Connect reader built in the P0 skeleton (0.5 pw, reused by P4).

## Pass bar (verbatim)

> ≥ 2 of 3 sources write golf workouts **with routes** on ≥ 1 OS. **The memo records a verdict per source**
> (A2-14), so a Garmin-source fail is visible even when X1 passes.

## Kill consequence (verbatim)

> Health lane ships **date-only** (§7.3 lane 1); store copy drops "GPS match"; result feeds K4.

## METHOD

1. Play one real round of golf carrying: a Garmin golf watch running Garmin Connect Mobile; an Apple Watch
   running a Workout (Golf activity type where offered); and one phone golf app (any of 18Birdies, Hole19,
   TheGrint, Golfshot, SwingU — the plan names these as no-public-API apps, §7.3 row "—").
2. After the round, on the iPhone: **Settings → Health → profile icon → Export All Health Data**, producing
   `export.zip` (containing `export.xml` and a `workout-routes/` folder of GPX files per workout)
   `[unverified — training knowledge]`.
3. Inspect `export.xml` for each of the 3 sources' `<Workout>` elements: record `workoutActivityType`,
   `HKSource.bundleIdentifier`, and whether a matching GPX route file exists in `workout-routes/` (⇒
   `HKWorkoutRoute` present).
4. Run the equivalent round (or a second round) on Android with Health Connect enabled, using the P0-skeleton
   Health Connect reader (`apps/mobile`, not yet built as of 2026-09-23 — a 0.5 pw prerequisite, reused by P4)
   to read the exercise type, route, and `dataOrigin` for each source that also has an Android app.
5. Record a **verdict per source** (Garmin, Apple Watch, phone app) × per OS, not just an overall pass/fail
   (A2-14) — a Garmin-source fail must stay visible even if the other two sources pass.
